# Contributing to Developer Learning Paths

We welcome contributions that improve the quality, clarity, and usefulness of the learning paths.

## What to contribute

- learning resources and reading lists
- new learning modules or topic roadmaps
- refinements to structure and sequencing
- clearer explanations of skills and prerequisites
- improvements to accessibility and clarity

## Contribution guidance

1. Identify the topic or learning gap.
2. Explain why the change helps learners.
3. Submit a pull request with a concise summary.
4. Keep content practical, useful, and easy to follow.

## Expectations

- be clear about the learner level and scope
- prioritize useful, non-generic content
- document recommendations with enough context to be actionable
- keep materials organized and readable

## Review standards

Contributions should make the learning path clearer and more practical for developers building real-world skills.
