# Developer Learning Paths

Curated learning paths for developers across AI, data engineering, and modern software practices.

This repository provides structured learning pathways designed for developers who want to build practical skills in AI systems, data engineering, software architecture, and community-driven development. Each path combines curated resources, hands-on projects, and real-world context.

## Mission

Developer Learning Paths exists to help engineers build deep, practical skills through structured learning. We believe the best learning is:
- goal-oriented and project-based
- grounded in real-world practice
- supported by community and mentorship
- transparent about progression and outcomes
- accessible to developers at all levels

## What this repository covers

- curated learning pathways by skill and role
- AI and machine learning foundations
- data engineering and pipeline architecture
- modern software delivery practices
- AI operations and governance
- contributor onboarding and community learning
- hands-on project guidance
- resource curation and recommendations

## Why this matters

Learning paths that are:
- structured and clear about progression
- practical and project-driven
- community-supported and transparent
- evidence-based and skill-focused

help developers move faster and with more confidence, while building real capabilities that transfer to their work.

## Core principles

- **Practical over theoretical** — learning should connect directly to real projects
- **Community-supported** — learning is more effective with mentors, peers, and feedback
- **Transparent progression** — learners should understand where they are and where they're going
- **Inclusive design** — paths should work for developers from different backgrounds and experience levels
- **Evidence-based** — recommendations should be based on practical experience, not hype
